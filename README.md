# Eye Color Classification Using Machine Learning

## Project Overview

This project was developed for the Data Mining course at Selçuk University in 2025.

The objective was to classify human eye images into three categories: Blue, Brown, and Green, using machine learning techniques.

## Tools and Technologies

- Orange Data Mining
- Machine Learning
- Neural Networks
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- SqueezeNet
- Image Embedding
- 10-Fold Cross-Validation

## Dataset

A custom dataset of 3,207 eye images was collected from online image sources and organized into three categories:

- Blue eyes
- Brown eyes
- Green eyes

SqueezeNet was used to extract numerical features from the images through the Image Embedding workflow in Orange Data Mining.

## Methodology

1. Image collection and dataset preparation
2. Image embedding using SqueezeNet
3. Training and evaluation of three classification algorithms
4. Model comparison using 10-fold cross-validation
5. Performance evaluation using Accuracy, Precision, Recall, F1-Score, and Confusion Matrices

## Experimental Results

| Model | Accuracy | F1-Score |
|---|---|---|
| Neural Network | 88.0% | 88.0% |
| SVM | 74.4% | 74.7% |
| KNN | 73.3% | 73.1% |

The Neural Network achieved the highest reported classification accuracy of 88.0%.
